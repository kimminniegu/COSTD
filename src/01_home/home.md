# COSMOA 홈 화면 명세서

| 항목 | 내용 |
|---|---|
| 프로젝트 | COSMOA (화장품 해외영업 업무지원 플랫폼) |
| 팀 | COSTD |
| 담당 범위 | 홈 화면 (화장품 최신 뉴스, 환율, 수출입 요약, 바이어 현지 시각, 규제 업데이트) |
| 기술 스택 | Flask, Jinja2 템플릿, Render 배포 |
| 문서 버전 | v0.5 (뉴스 출처 추가: 코스인코리아닷컴, 코스모닝, 식약처) |

## 1. 화면 개요

로그인 후 처음 보이는 화면이다. 해외영업 담당자가 **화장품 업계 최신 뉴스**를 중심으로, 환율과 수출 흐름, **바이어 현지 시각**, **해외 규제 업데이트**를 **스크롤 없이 한 화면에서** 확인한다.

| 구역 | 비중 | 내용 | 데이터 |
|---|---|---|---|
| 사이드바 | 고정 | 로고, 메뉴, 사용자 정보, 로그아웃 | 세션 |
| 상단 줄 | 작게 | 날짜·인사말, 환율 띠, 수출입 요약 카드 | 한국수출입은행 API, 관세청 API |
| 왼쪽: 화장품 최신 뉴스 | **가장 크게** (약 60%) | 화장품 전문지 5곳 + 식약처 기사를 하나의 목록으로 통합 | 장업신문, CMN, 뷰티누리, 코스인코리아닷컴, 코스모닝, 식약처 |
| 오른쪽 위: 바이어 현지 시각 | 작게 | 주요 수출국 현재 시각, 업무 시간 여부 | 외부 API 없음 (브라우저 계산) |
| 오른쪽 아래: 규제 업데이트 | 중간 | 해외 화장품 규제 관련 최신 소식 | KOTRA 단신속보뉴스 API, 구글 뉴스 RSS |

### 1-1. 변경 이력

| 버전 | 변경 내용 |
|---|---|
| v0.3 | 환율 그래프·환산기 삭제 → 환율 띠, 수출입은 작은 카드 1개, 바로가기 삭제, 페이지 스크롤 없음 |
| v0.4 | 뉴스를 왼쪽으로 줄이고 1열로 변경, 오른쪽에 바이어 현지 시각과 규제 업데이트 추가 |
| v0.5 | 바이어 시각 수출 상위국 / 직접 선택 모드, 뉴스 출처에 코스인코리아닷컴·코스모닝·식약처 추가 |

## 2. 화면 구성

기준 해상도는 **1440 × 900** 이다. 이 크기에서 페이지 전체가 스크롤 없이 들어가야 한다.

```
┌────────────┬──────────────────────────────────────────────────────┐
│ [로고]      │ 9월 22일 화요일 · [사용자명]님, 좋은 아침이에요       [알림] │
│ COSMOA     │                                                      │
│ by COSTD   │ ┌ 환율 ───────────────────────────────┐┌ 화장품 수출 ──┐ │
│            │ │ USD 1,385.20 ▲0.3%  JPY 938.40 ▼0.2% ││ 8월 $000.0M   │ │
│ 메뉴        │ │ CNH  EUR  THB  (1줄)                ││ ▲0.0% 전년비  │ │
│ ■ 홈        │ └─────────────────────────────────────┘└──────────────┘ │
│ □ 인허가규제  │                                                      │
│ □ 개발요청서  │ ┌ 화장품 최신 뉴스 ──────────┐ ┌ 바이어 현지 시각 ──────┐ │
│ □ AI 샘플    │ │ [장업신문] 기사 제목 ...    │ │ 뉴욕   21:32  업무 외  │ │
│ □ 원가·마진  │ │ 3시간 전                  │ │ 베이징 09:32  업무 중  │ │
│            │ │ [CMN] 기사 제목 ...        │ │ 도쿄   10:32  업무 중  │ │
│            │ │ 4시간 전                  │ │ 파리   03:32  업무 외  │ │
│            │ │ [뷰티누리] 기사 제목 ...    │ └──────────────────────┘ │
│            │ │ ...                      │ ┌ 규제 업데이트 ─── 실시간 ┐ │
│            │ │ (1열, 약 7~8건)           │ │ [미국] 규제 소식 제목 NEW│ │
│            │ │                          │ │ [EU]  규제 소식 제목     │ │
│ [프로필]     │ │                          │ │ [중국] 규제 소식 제목    │ │
│ 로그아웃     │ └──────────────────────────┘ └──────────────────────┘ │
│            │                    뉴스 더보기 →            규제 더보기 → │
└────────────┴──────────────────────────────────────────────────────┘
        왼쪽 약 60% (뉴스)                오른쪽 약 40% (시각 + 규제)
```

### 2-1. 크기 배분 (1440 × 900 기준)

| 구역 | 크기 | 비고 |
|---|---|---|
| 위아래 여백 | 32px × 2 | |
| 인사말 줄 | 높이 약 48px | 날짜와 인사말을 한 줄로 |

| 오른쪽 열 | 폭 약 40% | 위: 현지 시각 약 200px, 아래: 규제 업데이트 나머지 |
| 구역 사이 간격 | 20~24px | |

### 2-3. 상단 정보 줄

**인사말**

| 요소 | 내용 |
|---|---|
| 날짜 + 인사말 | 9월 22일 화요일 · [사용자명]님, 좋은 아침이에요 (한 줄, 18px) |
| 알림 버튼 | 오른쪽 끝, 아이콘만. 새 규제 소식이 있으면 빨간 점 표시 (8-4 참고) |

**환율 띠** (가로 약 2/3)

| 요소 | 내용 |
|---|---|
| 표시 통화 | USD / JPY(100) / CNH / EUR / THB (+ 1개 팀 결정) 를 한 줄에 나란히 |
| 통화 하나 | 통화 코드, 매매기준율, 전일 대비 등락률(▲▼) |
| 기준 표시 | 띠 오른쪽 끝에 작게 "수출입은행 · 9/22 기준" |
| 마우스 올림 | 통화명과 단위를 툴팁으로 표시 (예: 일본 엔, 100엔 기준) |
| 없는 것 | 그래프, 환산기, 통화 선택 기능 없음 |

**화장품 수출 요약 카드** (가로 약 1/3)

| 요소 | 내용 |
|---|---|
| 제목 | 화장품 수출 · 8월 (최근 발표 월) |
| 숫자 | 수출액 (백만 달러), 전년 동월 대비 증감률 |
| 보조 줄 | 수입액, 무역수지를 작은 글씨로 한 줄 |
| 링크 | "K-stat" 작은 링크 → https://stat.kita.net/ |
| 없는 것 | 추이 그래프, 국가별 순위 없음 |

### 2-4. 왼쪽: 화장품 최신 뉴스

| 요소 | 내용 |
|---|---|
| 제목 줄 | 화장품 최신 뉴스 + 오른쪽에 마지막 업데이트 시각 |
| 기사 목록 | 전체 출처 기사를 합쳐 최신순, **1열 약 7~8건** (화면 높이에 맞춤) |
| 기사 한 칸 | 출처 뱃지(장업신문 / CMN / 뷰티누리 / 코스인 / 코스모닝 / 식약처), 기사 제목(최대 2줄, 넘치면 …), 게시 시간 |
| 공식 발표 표시 | 식약처 보도자료는 뱃지 색을 달리해 공식 발표임을 구분 |
| 클릭 | 원문 기사 페이지를 새 탭으로 열기 |
| 뉴스 더보기 | 목록 아래 오른쪽. 전체 뉴스 목록 페이지로 이동 (여기서는 스크롤 허용) |
| 탭 | 없음 (팀 의견에 따라 매체 통합) |

기사 본문, 요약문, 사진은 표시하지 않는다 (6-5 참고).

### 2-5. 오른쪽 위: 바이어 현지 시각

| 요소 | 내용 |
|---|---|
| 제목 | 바이어 현지 시각 |
| 보기 전환 | 카드 오른쪽 위 작은 전환 버튼: **수출 상위국** (기본) / **내가 선택** |
| 수출 상위국 | 한국 화장품 수출액 상위 4개국의 시각을 자동 표시 (관세청 데이터 기준, 7-2 참고) |
| 내가 선택 | 사용자가 고른 최대 4곳 표시, "편집"으로 변경 (7-3 참고) |
| 한 줄 구성 | 도시명 · 국기 대신 국가 코드 · 현재 시각(HH:MM) · 한국과의 시차(예: −13h) · 업무 상태 뱃지 |
| 업무 상태 | 업무 중(현지 평일 09~18시) / 업무 외 / 주말 |
| 갱신 | 시각은 1분마다 화면에서 자동 갱신, 수출 상위국 순위는 월 1회 |

자세한 동작은 7장.

### 2-6. 오른쪽 아래: 규제 업데이트

| 요소 | 내용 |
|---|---|
| 제목 줄 | 규제 업데이트 + "실시간" 표시 + 마지막 확인 시각 |
| 목록 | 해외 화장품 규제 관련 최신 소식 4~5건 (화면 높이에 맞춤) |
| 한 줄 구성 | 국가 뱃지(미국 / EU / 중국 / 일본 / 동남아 …), 제목(최대 2줄), 출처(KOTRA / 언론사), 시간 |
| 새 소식 표시 | 24시간 이내 소식에 NEW 뱃지 |
| 클릭 | 원문 새 탭 열기 |
| 규제 더보기 | 국가별 인허가규제 탭으로 이동 (해당 국가가 선택된 상태로 열면 좋음) |

자세한 동작은 8장.

### 2-7. 한 화면 유지 규칙

| 규칙 | 내용 |
|---|---|
| 페이지 높이 | `height: 100vh`, 본문 `overflow: hidden` |
| 아래 영역 | 남은 높이를 모두 차지 (`flex: 1`), 왼쪽·오른쪽 열 높이 동일 |
| 목록 개수 조정 | 뉴스·규제 목록 모두, 영역 높이 ÷ 한 칸 높이만큼만 표시. 목록 안 스크롤 없음 |
| 제목 넘침 | 2줄에서 자르고 … 표시 (`-webkit-line-clamp: 2`) |
| 좁은 화면 | 폭 1024px 미만이면 오른쪽 열을 뉴스 아래로 내리고 페이지 스크롤 허용 (한 화면 규칙은 데스크톱 기준) |

서버는 뉴스 12건, 규제 8건을 보내고 화면에서 보이는 만큼만 표시한다.

## 3. 디자인 가이드

로그인 화면과 같은 색상, 글꼴을 쓴다. 홈에서 추가되는 값만 적는다.

| 이름 | 값 | 사용처 |
|---|---|---|
| 화면 배경 | `#F2F4F6` | 본문 배경 |
| 카드 배경 | `#FFFFFF` | 환율 띠, 수출입 카드, 뉴스, 현지 시각, 규제 업데이트 (모서리 20px) |
| 상승 | `#E42939` | 환율·수출 증가 (▲) |
| 하락 | `#1B64DA` | 환율·수출 감소 (▼) |
| 출처 뱃지 | `#F2F4F6` 배경 + `#4E5968` 글자 | 뉴스 매체명 |
| 기사 구분선 | `#F2F4F6` 1px | 뉴스·규제 칸 사이 |
| 업무 중 뱃지 | `#E5F7EE` 배경 + `#0B7A4B` 글자 | 현지 시각 |
| 업무 외·주말 뱃지 | `#F2F4F6` 배경 + `#6B7684` 글자 | 현지 시각 |
| 국가 뱃지 | `#E8F3FF` 배경 + `#1B64DA` 글자 | 규제 업데이트 |
| NEW 뱃지 | `#FDECEE` 배경 + `#C8102E` 글자 | 규제 업데이트 24시간 이내 |

| 요소 | 글자 크기 |
|---|---|
| 인사말 | 18px |
| 환율 숫자 | 16px Bold |
| 수출액 숫자 | 22px Bold |
| 뉴스 제목 | 16px Semibold, 2줄 |
| 뉴스 시간·출처 | 13px |
| 현지 시각 숫자 | 18px Bold |
| 규제 제목 | 15px Semibold, 2줄 |

숫자는 자릿수가 흔들리지 않도록 `font-variant-numeric: tabular-nums`를 적용한다. 등락 색은 국내 관례대로 상승 빨강, 하락 파랑이다.

## 4. 환율 기능

### 4-1. 데이터 출처

| 항목 | 내용 |
|---|---|
| API | 한국수출입은행 현재환율 API (공공 Open API, 무료) |
| 발급 | 한국수출입은행 Open API 페이지에서 인증키 발급 |
| 요청 값 | `authkey`(인증키), `searchdate`(조회일, YYYYMMDD), `data=AP01`(환율) |
| 사용 값 | `cur_unit`(통화 코드), `cur_nm`(통화명), `deal_bas_r`(매매기준율) |
| 인증키 보관 | 코드에 쓰지 않고 Render 환경변수 `EXIM_API_KEY`에 등록 |

요청 주소는 기관 사정으로 바뀔 수 있으니 개발 시점에 공식 안내 페이지의 주소를 확인한다.

### 4-2. 개발 전 확인할 점

| 확인 사항 | 내용 |
|---|---|
| 갱신 시각 | 영업일 오전에 그날 환율이 올라온다. 이른 시간, 주말, 공휴일에는 빈 결과가 온다 → 가장 최근 영업일 값을 표시 |
| 통화 코드 | 위안화는 `CNH`(역외 위안화)로 제공된다 |
| 제공 통화 | 베트남 동(VND)은 제공 목록에 없는 것으로 보인다 → 실제 응답으로 확인 후, 없으면 SGD, MYR 등으로 교체 |
| 100단위 통화 | `JPY(100)`처럼 100 단위로 오는 통화는 단위를 함께 표시 |
| 숫자 형식 | `deal_bas_r`가 `"1,385.2"`처럼 쉼표 포함 문자열로 온다 → 쉼표 제거 후 숫자 변환 |
| 호출 제한 | 하루 호출 횟수 제한이 있으므로 화면 접속마다 호출하지 않는다 |

### 4-3. 데이터 흐름

그래프와 환산기를 뺐으므로 **오늘 값과 직전 영업일 값 두 개만** 있으면 된다.

| 단계 | 내용 |
|---|---|
| 확인 주기 | 홈 접속 시, 오늘 날짜 환율이 저장돼 있지 않으면 조회 (하루 최대 몇 번) |
| 최근 영업일 찾기 | 오늘 결과가 비어 있으면 하루씩 앞으로 가며 값이 있는 날까지 조회 (최대 7일) |
| 직전 영업일 | 같은 방식으로 그 전 영업일 값 확보 |
| 전일 대비 | (최근 값 − 직전 값) ÷ 직전 값 × 100 |
| 저장 | 날짜별로 저장해 두면 서버가 재시작돼도 다시 조회만 하면 됨 |

```python
def to_float(s):
    return float(s.replace(",", ""))

change_pct = (today_rate - prev_rate) / prev_rate * 100
```

## 5. 화장품 수출입 요약 기능

### 5-1. 데이터 출처 결정

| 방법 | 문제점 / 장점 | 결정 |
|---|---|---|
| K-stat에 팀 계정으로 자동 로그인해 크롤링 | 공개 API 없음. 계정 비밀번호를 서버에 저장해야 함. 회원용 데이터 재표시는 이용약관 위반 소지. 로그인 방식이 바뀌면 중단 | 자동 수집에는 쓰지 않음 |
| 관세청_품목별 국가별 수출입실적(GW) API | 공공데이터포털 무료 REST API. HS 코드별 수출·수입 금액, 무역수지 제공 | **사용** |

국내 수출입 통계는 K-stat도 관세청 통관 자료를 바탕으로 하므로 같은 원천의 숫자다. K-stat은 개발 중 **수치 검증용**으로 쓰고, 카드에 **링크**로 연결해 사용자가 직접 상세 조회하게 한다.

### 5-2. API 정보

| 항목 | 내용 |
|---|---|
| 이름 | 관세청_품목별 국가별 수출입실적(GW) |
| 신청 | 공공데이터포털(data.go.kr) 활용신청 → 개발계정 자동 승인 |
| 형식 | REST, XML 응답 |
| 트래픽 | 개발계정 하루 10,000건 |
| 사용 값 | `hsCd`(HS 코드), `expDlr`(수출금액, 달러), `impDlr`(수입금액, 달러), `balPayments`(무역수지, 달러) |
| 인증키 보관 | Render 환경변수 `DATA_GO_KR_KEY` |

요청 주소와 요청 변수(조회 기간, HS 코드 등)의 정확한 이름은 공공데이터포털에서 받는 기술문서로 확인한다.

### 5-3. 화장품 HS 코드

| HS 코드 | 품목 |
|---|---|
| 3303 | 향수, 화장수 |
| 3304 | 미용·메이크업·기초화장품 (선크림, 매니큐어 포함) |
| 3305 | 두발용 제품 |
| 3307 | 면도용, 탈취제, 입욕제 등 |

기본값은 **3304** 하나. 3303·3305·3307까지 합칠지는 팀에서 정한다 (3306 치약·구강용품은 제외).

### 5-4. 필요한 데이터와 갱신

카드 하나만 보여주므로 **최근 발표 월**과 **전년 같은 달** 두 달 치만 있으면 된다.

| 항목 | 내용 |
|---|---|
| 조회 | 최근 13개월 범위로 한 번 조회해 최근 월과 전년 동월 값을 꺼냄 |
| 확인 주기 | 하루 한 번, 새 달 데이터가 올라왔는지 확인 (접속 시 확인 방식) |
| 수정 반영 | 최근 2개월 값은 수정될 수 있으므로 갱신 때마다 덮어쓰기 |
| 표시 단위 | 달러 금액 ÷ 1,000,000 → 백만 달러, 소수 첫째 자리 |
| 증감률 | (최근 월 수출액 − 전년 동월 수출액) ÷ 전년 동월 수출액 × 100 |

### 5-5. 조회 코드 (예시)

```python
import os
import requests
import xml.etree.ElementTree as ET

TRADE_URL = "기술문서에 적힌 요청 주소"


def fetch_trade(start_yymm, end_yymm, hs_code="3304"):
    params = {
        "serviceKey": os.environ["DATA_GO_KR_KEY"],
        "strtYymm": start_yymm,   # 변수 이름은 기술문서로 확인
        "endYymm": end_yymm,
        "hsSgn": hs_code,
    }
    res = requests.get(TRADE_URL, params=params, timeout=10)
    root = ET.fromstring(res.content)
    return [{
        "yymm": item.findtext("year"),          # 기준 연월 항목명도 확인
        "exp_usd": float(item.findtext("expDlr") or 0),
        "imp_usd": float(item.findtext("impDlr") or 0),
        "balance": float(item.findtext("balPayments") or 0),
    } for item in root.iter("item")]
```

### 5-6. 실패 처리

| 상황 | 화면 동작 |
|---|---|
| API 오류 | 저장된 최근 값 표시 |
| 저장된 값 없음 | 카드에 "수출 실적을 불러오지 못했어요" + K-stat 링크만 표시 |
| 이번 달 데이터 아직 없음 | 가장 최근 발표 월 기준으로 표시 (정상 동작) |

환율 띠도 같은 방식으로, 실패하면 저장된 최근 값을 보여주고 값이 없으면 "환율 정보를 불러오지 못했어요"를 한 줄로 표시한다. 상단이 실패해도 뉴스 영역은 그대로 나와야 한다.

| 공식 기관 (추가) | 식품의약품안전처 | https://www.mfds.go.kr/ | 공식 RSS | 보도자료 RSS에서 제목에 "화장품"이 들어간 글만 사용 |

**코스인코리아닷컴 · 코스모닝**
두 사이트는 같은 뉴스 관리 시스템을 써서 목록 구조가 같다. 전체기사 목록 페이지(`/news/article_list_all.html`)에서 기사 링크(`/news/article.html?no=숫자`)와 작성 시각(`2026-09-22 10:56` 형식)을 뽑는 **파서 하나로 두 곳을 같이 처리**한다.

**식약처 보도자료 RSS**
식약처는 게시판별 RSS를 제공하며, 보도자료 RSS 주소는 `http://www.mfds.go.kr/www/rss/brd.do?brdId=ntc0021` 이다. 식품·의약품 소식도 섞여 있으므로 제목 키워드(화장품, 기능성화장품, 자외선차단제 등)로 거른다.

**뷰티누리용 구글 뉴스 RSS 주소**

```
https://news.google.com/rss/search?q=site:beautynury.com&hl=ko&gl=KR&ceid=KR:ko
```

구글 뉴스 RSS는 기사 제목 끝에 ` - 뷰티누리` 같은 매체명이 붙어 오므로 잘라서 저장한다.

**해외 전문지 (선택, 2차)**
영문 화장품 업계지(예: CosmeticsDesign, Cosmetics Business)도 구글 뉴스 RSS의 `site:` 검색으로 받을 수 있다. 제목이 영어라서, 넣는다면 출처 뱃지 옆에 "EN" 표시를 붙인다. 1차 버전에서는 국내 출처만으로 시작한다.

### 6-6. 수집 코드 (예시)

```python
import time
import requests
import feedparser
from bs4 import BeautifulSoup
from urllib.parse import urljoin

HEADERS = {"User-Agent": "COSMOA-news-bot (school project)"}
JANGUP_RSS = "여기에 장업신문 RSS 페이지에서 확인한 전체기사 피드 주소"
BEAUTYNURY_RSS = "https://news.google.com/rss/search?q=site:beautynury.com&hl=ko&gl=KR&ceid=KR:ko"


def fetch_jangup():
    feed = feedparser.parse(JANGUP_RSS)
    return [{"source": "장업신문", "title": e.title, "url": e.link,
             "published": e.get("published_parsed")} for e in feed.entries]


def fetch_cmn():
    res = requests.get("https://www.cmn.co.kr/main/", headers=HEADERS, timeout=10)
    soup = BeautifulSoup(res.text, "html.parser")
    items, seen = [], set()
    for a in soup.select('a[href*="news_view.asp?news_idx="]'):
        title = a.get_text(strip=True)
        url = urljoin("https://www.cmn.co.kr", a["href"]).split("&")[0]
        if title and url not in seen:
            seen.add(url)
            items.append({"source": "CMN", "title": title, "url": url, "published": None})
    return items


def fetch_beautynury():
    feed = feedparser.parse(BEAUTYNURY_RSS)
    return [{"source": "뷰티누리", "title": e.title.rsplit(" - ", 1)[0], "url": e.link,
             "published": e.get("published_parsed")} for e in feed.entries]


import re

DATE_RE = re.compile(r"\d{4}-\d{2}-\d{2} \d{2}:\d{2}")


def fetch_mediaon(source, base):
    """코스인코리아닷컴 · 코스모닝 공통 (같은 목록 구조)"""
    res = requests.get(base + "/news/article_list_all.html", headers=HEADERS, timeout=10)
    soup = BeautifulSoup(res.text, "html.parser")
    items, seen = [], set()
    for a in soup.select('a[href*="/news/article.html?no="]'):
        url = urljoin(base, a["href"])
        if url in seen:
            continue
        text = a.get_text(" ", strip=True)
        strong = a.find(["strong", "b"])
        title = strong.get_text(strip=True) if strong else text[:120]
        date = DATE_RE.search(text)
        seen.add(url)
        items.append({"source": source, "title": title, "url": url,
                      "published": date.group() if date else None})
    return items


def fetch_cosinkorea():
    return fetch_mediaon("코스인", "https://www.cosinkorea.com")


def fetch_cosmorning():
    return fetch_mediaon("코스모닝", "https://www.cosmorning.com")


MFDS_RSS = "http://www.mfds.go.kr/www/rss/brd.do?brdId=ntc0021"
MFDS_WORDS = ["화장품", "기능성화장품", "자외선차단", "맞춤형화장품"]


def fetch_mfds():
    feed = feedparser.parse(MFDS_RSS)
    return [{"source": "식약처", "title": e.title, "url": e.link,
             "published": e.get("published_parsed")}
            for e in feed.entries if any(w in e.title for w in MFDS_WORDS)]


def collect_all():
    results = []
    for fetch in (fetch_jangup, fetch_cmn, fetch_beautynury,
                  fetch_cosinkorea, fetch_cosmorning, fetch_mfds):
        try:
            results += fetch()
        except Exception as err:          # 한 매체가 실패해도 나머지는 계속
            print(fetch.__name__, "실패:", err)
        time.sleep(1.5)
    return results
```

CMN 메인에는 같은 기사가 여러 번 나오고 요약문 링크도 섞여 있어서, 링크 기준으로 중복을 제거하고 제목이 너무 긴 항목(요약문)은 걸러낸다. 사이트 구조가 바뀌면 선택자를 다시 맞춰야 한다. 코스인코리아닷컴·코스모닝 목록의 기사 링크 안에는 제목과 요약이 함께 들어 있으므로, 굵은 글씨(제목) 부분만 쓰고 요약은 저장하지 않는다.

## 7. 바이어 현지 시각 기능

### 7-1. 동작 방식

외부 API 없이 **브라우저에서 계산**한다. 시간대 이름(IANA)만 정해 두면 서머타임도 자동으로 반영된다.

| 항목 | 내용 |
|---|---|
| 계산 | 자바스크립트 `Intl.DateTimeFormat`에 시간대 이름을 넣어 현지 시각 계산 |
| 갱신 | 1분마다 다시 계산 (매 분 0초에 맞춰 갱신) |
| 서머타임 | 미국·유럽은 계절에 따라 시차가 바뀌며, 시간대 이름을 쓰면 자동 반영 |
| 시차 표시 | 한국 시각과 현지 시각 차이를 시간 단위로 표시 (예: −13h) |
| 업무 상태 | 현지 월~금 09:00~18:00이면 업무 중, 그 외 업무 외, 토·일은 주말 |

### 7-2. 수출 상위국 모드 (기본)

한국 화장품 수출액이 많은 나라 순서대로 4곳의 시각을 보여준다. 바이어가 많은 나라를 따로 고르지 않아도 되고, 순위가 바뀌면 자동으로 따라간다.

| 항목 | 내용 |
|---|---|
| 데이터 | 5장의 관세청 품목별 국가별 수출입실적 API를 **국가별**로 조회 (HS 3304 또는 팀이 정한 화장품 HS 범위) |
| 기준 기간 | 최근 12개월 누계 수출액 (한 달 실적만 보면 순위가 자주 흔들림) |
| 순위 갱신 | 월 1회, 새 달 수출 실적이 들어올 때 함께 계산 |
| 같은 시간대 합치기 | 홍콩·대만·싱가포르는 중국과 시각이 같으므로 이미 같은 시간대가 있으면 건너뛰고 다음 순위 국가를 넣음 |
| 순위 표시 | 도시명 앞에 작게 순위 표시 (예: 1 중국 · 베이징) |
| 데이터가 없을 때 | 기본 목록 사용: 중국, 미국, 일본, 베트남 (개발 시 K-stat 또는 관세청 조회로 실제 순위 확인 후 확정) |

국가별 조회는 호출 수가 늘어나지만 월 1회만 계산하므로 공공데이터포털 트래픽에 부담이 없다.

## 8. 규제 업데이트 기능

### 8-1. 데이터 출처

| 출처 | 방법 | 내용 |
|---|---|---|
| KOTRA 단신속보뉴스 | 공공데이터포털 Open API (무료, REST, JSON·XML) | KOTRA 해외무역관이 올리는 현지 통상·규제 소식. 수입규제, 정책동향 등 키워드로 분류된 단신 |
| 구글 뉴스 RSS 검색 | RSS | 화장품 규제 키워드 검색 결과 (국내·해외 언론) |
| (선택) KOTRA 해외인증정보 | 공공데이터포털 Open API | 국가별 인증 제도 정보. 규제 탭 담당 팀원과 공유 가능 |
| (선택) 식약처 행정예고 · 법령 RSS | 공식 RSS | 국내 화장품 규제 개정 소식 (`brdId=data0009` 행정예고, `brdId=data0008` 최근 개정 법령). 국가 뱃지는 "한국" |

KOTRA API는 수출입 실적과 같은 공공데이터포털 인증키(`DATA_GO_KR_KEY`)로 신청한다. 요청 주소와 변수 이름은 포털의 참고문서로 확인한다.

구글 뉴스 RSS 검색 주소 예시:

```
https://news.google.com/rss/search?q=화장품+(규제+OR+금지성분+OR+등록+OR+라벨링)&hl=ko&gl=KR&ceid=KR:ko
https://news.google.com/rss/search?q=cosmetics+regulation+(MoCRA+OR+CPNP+OR+NMPA)&hl=en-US&gl=US&ceid=US:en
```

실제 주소에는 한글과 공백을 URL 인코딩해서 넣는다 (`requests`의 `params`를 쓰면 자동 처리).

### 8-2. 화장품 규제 소식 골라내기

KOTRA 단신은 화장품 외 소식도 많으므로 **키워드 필터**를 거친다.

| 단계 | 조건 |
|---|---|
| 1. 화장품 관련 | 제목·요약에 화장품, 코스메틱, cosmetic, 뷰티, 스킨케어, 선크림 등 포함 |
| 2. 규제 관련 | 규제, 금지, 제한, 등록, 인증, 허가, 성분, 표시, 라벨, 개정, 시행, 통관 등 포함 |
| 3. 국가 태그 | 국가명·기관명으로 국가 뱃지 결정 (아래 표) |
| 4. 중복 제거 | 같은 링크 또는 거의 같은 제목은 하나만 |

| 키워드 | 국가 뱃지 |
|---|---|
| 미국, FDA, MoCRA | 미국 |

키워드 목록은 코드에 고정하지 말고 설정 파일로 빼서, 규제 탭 담당 팀원과 같이 쓴다.

### 8-3. "실시간" 수집 방식

완전한 실시간(푸시)은 두 출처 모두 지원하지 않으므로 **짧은 간격으로 새 소식을 확인**하는 방식으로 실시간에 가깝게 만든다.

| 항목 | 내용 |
|---|---|
| 확인 간격 | **1시간** (뉴스의 6시간보다 짧게) |
| 서버 쪽 | 홈 접속 시 마지막 확인이 1시간 넘었으면 새로 수집 (Render 무료 플랜이 잠들어도 동작) |
| 화면 쪽 | 홈을 열어 둔 상태에서는 10분마다 `/api/regulations`를 불러 새 소식이 있으면 목록 맨 위에 추가 |
| 표시 | 제목 줄에 "실시간 · 14:05 확인" |
| 호출량 | 1시간 간격이면 하루 24회 수준으로 공공데이터포털 개발계정 트래픽(하루 10,000건)에 여유 |

### 8-4. 새 소식 알림

| 항목 | 내용 |
|---|---|
| NEW 뱃지 | 게시 24시간 이내 소식 |
| 알림 점 | 사용자가 마지막으로 홈을 본 뒤 새 규제 소식이 생기면 상단 알림 버튼에 빨간 점 |
| 알림 목록 | 알림 버튼을 누르면 새 규제 소식 목록 (선택 사항) |
| 관심 국가 (선택) | 사용자가 관심 국가를 정하면 해당 국가 소식만 알림 |

### 8-5. 수집 코드 (예시)

```python
import requests
import feedparser

COSMETIC_WORDS = ["화장품", "코스메틱", "cosmetic", "뷰티", "스킨케어", "선크림"]
REG_WORDS = ["규제", "금지", "제한", "등록", "인증", "허가", "성분", "표시", "라벨",
             "개정", "시행", "통관", "regulation", "ban"]
COUNTRY_TAGS = {
    "미국": ["미국", "FDA", "MoCRA"],
    "EU": ["EU", "유럽", "CPNP"],
    "중국": ["중국", "NMPA"],
    "일본": ["일본", "후생노동성"],
    "동남아": ["베트남", "태국", "인도네시아", "말레이시아", "BPOM", "아세안"],
    "중동": ["사우디", "UAE", "SFDA", "할랄"],
}


def is_cosmetic_regulation(text):
    t = text.lower()
    return any(w.lower() in t for w in COSMETIC_WORDS) and any(w.lower() in t for w in REG_WORDS)


def country_tag(text):
    for tag, words in COUNTRY_TAGS.items():
        if any(w.lower() in text.lower() for w in words):
            return tag
    return "기타"


def fetch_google_regulations():
    url = "https://news.google.com/rss/search"
    params = {"q": "화장품 (규제 OR 금지성분 OR 등록 OR 라벨링)",
              "hl": "ko", "gl": "KR", "ceid": "KR:ko"}
    res = requests.get(url, params=params, timeout=10)
    feed = feedparser.parse(res.content)
    items = []
    for e in feed.entries:
        title, _, press = e.title.rpartition(" - ")
        if is_cosmetic_regulation(title):
            items.append({"country": country_tag(title), "title": title,
                          "source": press, "url": e.link,
                          "published": e.get("published_parsed")})
    return items

# KOTRA 단신속보뉴스는 기술문서의 요청 주소·변수로 조회한 뒤
# 제목+요약 텍스트에 is_cosmetic_regulation(), country_tag()를 똑같이 적용한다.
```

### 8-6. 표시 범위와 실패 처리

| 항목 | 내용 |
|---|---|
| 표시 범위 | 제목, 국가, 출처, 시간, 원문 링크만 (뉴스와 같은 저작권 규칙, 6-4 참고) |
| 정렬 | 게시 시간 최신순, 서버는 최근 8건 전달 |
| 한 출처 실패 | 다른 출처 소식만 표시 |
| 전체 실패 | 저장된 목록 표시 + 마지막 확인 시각 그대로 |
| 소식 없음 | "최근 규제 소식이 없어요" + 규제 더보기 링크 |

규제 업데이트는 **소식 알림**이고, 정확한 규제 내용은 국가별 인허가규제 탭과 원문으로 확인하도록 안내한다.

```python
def top_export_cities(rows, city_map, n=4):
    # rows: [{"country": "CN", "exp_usd": ...}, ...] 최근 12개월 국가별 합계
    picked, used_tz = [], set()
    for r in sorted(rows, key=lambda x: x["exp_usd"], reverse=True):
        city = city_map.get(r["country"])      # 7-4 표
        if not city or city["tz_offset_key"] in used_tz:
            continue
        used_tz.add(city["tz_offset_key"])       # 같은 시각인 시간대 중복 방지
        picked.append({"rank": len(picked) + 1, **city})
        if len(picked) == n:
            break
    return picked
```

`tz_offset_key`는 한국과의 시차가 같은 시간대를 하나로 묶기 위한 값이다 (예: 베이징·홍콩·타이베이·싱가포르는 같은 값).

**user_settings** (선택)

| 컬럼 | 타입 | 설명 |
|---|---|---|
| user_id | INTEGER | 사용자 |
| clock_mode | TEXT | 현지 시각 보기 방식: top_export / custom |
| cities | TEXT | 내가 선택한 도시 목록 (JSON) |
| interest_countries | TEXT | 규제 알림 관심 국가 (JSON) |
| last_seen_reg_at | DATETIME | 알림 점 표시 기준 |

Render 무료 플랜에서 SQLite 파일은 서버 재시작 때 지워질 수 있다. 환율·수출입·뉴스·규제 데이터는 모두 필요한 기간이 짧아서, 비어 있으면 다시 조회해 채우면 된다.

## 11. 체크리스트

- [ ] `EXIM_API_KEY`, `DATA_GO_KR_KEY`를 Render 환경변수에 등록
- [ ] 1440 × 900 화면에서 페이지 스크롤 없이 전체가 보이는지 확인
- [ ] 1366 × 768 화면에서 뉴스 행 수가 줄어들고 스크롤이 생기지 않는지 확인
- [ ] 주말·공휴일·오전 이른 시간에도 최근 영업일 환율과 등락률이 표시되는지 확인
- [ ] 화장품 수출액이 K-stat 조회 결과와 같은 기간·HS 코드 기준으로 일치하는지 확인
- [ ] 뉴스 목록이 6개 출처 통합, 최신순, 1열로 나오는지 확인
- [ ] 한 출처가 목록을 독차지하지 않는지(출처당 최대 건수) 확인
- [ ] 같은 보도자료를 여러 매체가 쓴 경우 1건만 나오는지 확인
- [ ] 식약처 보도자료 중 화장품 관련 글만 나오는지 확인
- [ ] 수출 상위국 모드에서 4곳이 수출액 순서대로, 같은 시간대 중복 없이 나오는지 확인
- [ ] "내가 선택"으로 바꾼 도시가 다시 접속해도 유지되는지 확인
- [ ] 현지 시각이 1분마다 바뀌고, 서머타임 기간에도 시차가 맞는지 확인 (예: 뉴욕 여름 −13h, 겨울 −14h)
- [ ] 현지 주말·업무 외 시간 뱃지가 맞게 나오는지 확인
- [ ] 규제 목록에 화장품과 관계없는 소식이 섞이지 않는지 확인 (키워드 필터)

- [ ] 긴 기사 제목이 2줄에서 잘리는지 확인
- [ ] 6시간 안에 다시 접속하면 수집하지 않고 저장된 목록을 쓰는지 확인
- [ ] 환율·수출입 API가 실패해도 뉴스 영역은 정상으로 나오는지 확인
- [ ] 기사 클릭 시 원문이 새 탭으로 열리는지 확인
- [ ] 화면에 기사 본문·사진이 들어가 있지 않은지 확인
